    Le masque de sous-réseau et l’adresse IP sont indissociables : le masque indique quelle partie de l’adresse identifie le réseau et quelle partie identifie la machine.
    
  
    
    
    Observe l’effet du masque
    
    
    
      
      
      
    
    
    
    
    
    
  
    

  
    
    
    
      
    1. Masque 255.255.255.0 : combien de machines ce réseau peut-il accueillir ?
    
      
    machines
    
      
    
      
      
    Avec le masque 255.255.255.0, seul le dernier octet est réservé aux machines. Un octet = 8 bits = 256 nombres (de 0 à 255). Les nombres 0 et 255 sont réservés, il reste les nombres de 1 à 254.
    Ce réseau peut accueillir 254 machines.
    
    
    
    
    
      
    2. Même question avec le masque 255.255.0.0
    
      
    machines
    
      
    
      
      
    Avec le masque 255.255.0.0, les deux derniers octets sont réservés aux machines : 256 × 256 = 65 536 combinaisons (de x.x.0.0 à x.x.255.255). Seules la première (x.x.0.0) et la dernière (x.x.255.255) sont réservées.
    Ce réseau peut accueillir 65 534 machines.
    
    
    
  
    

  
    
    
    3. Masque 255.255.255.0 : quelles machines peuvent communiquer avec 10.20.6.11 ?
    
    
    Clique sur les adresses qui conviennent.
    
    
    
    
    
    
    
    
    10.20.6.1, 10.20.6.2, 10.20.6.3, 10.20.6.4 et 10.20.6.6 peuvent communiquer avec 10.20.6.11.
    Avec le masque 255.255.255.0, les 3 premiers nombres doivent être identiques pour appartenir au même réseau.
    
  
    
  
    
    
    4. Même question avec le masque 255.255.0.0
    
    
    
    
    
    
    
    
    10.20.6.1, 10.20.6.2, 10.20.6.3, 10.20.6.4, 10.20.6.6, 10.20.7.5 et 10.20.5.10 peuvent communiquer avec 10.20.6.11.
    Avec le masque 255.255.0.0, seuls les 2 premiers nombres doivent être identiques pour appartenir au même réseau.

    11000000 = 128 + 64 = 192
