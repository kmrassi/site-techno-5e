Les connexions du réseau

Le logiciel de simulation réseau Filius propose un seul type de câble, représenté en rouge. Dans le collège, les équipements sont reliés par des câbles réseau branchés sur leur carte réseau, ou sans fil (WiFi).

Lancer un test de communication entre une station et le serveur

Dans Filius. Clique sur chaque étape quand elle est faite.

  1. Cliquer sur le mode simulation (bouton ▶ vert).
  2. Cliquer sur la station de travail à tester.
  3. Cliquer sur Installation des logiciels.
  4. Sélectionner Ligne de commande dans les logiciels disponibles.
  5. Cliquer sur la flèche ◀ puis sur Appliquer les modifications.
  6. Ouvrir le logiciel Ligne de commande.
  7. Après l’invite de commande />, saisir ping 192.168.1.254
  8. Valider en appuyant sur la touche Entrée.
